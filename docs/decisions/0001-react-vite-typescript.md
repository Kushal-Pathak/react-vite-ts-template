# ADR-0001: Use React, Vite, and TypeScript

## Status

Accepted

## Context

The template needs a modern, simple, and reusable frontend foundation.

## Decision

Use React for UI, Vite for development/builds, and TypeScript for static typing.

## Consequences

### Benefits

- fast development environment
- strong TypeScript support
- simple setup
- broad ecosystem

### Trade-offs

- routing, data fetching, and other application concerns are added only when needed
