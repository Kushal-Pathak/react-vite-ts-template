# ADR-0003: Use Tailwind CSS and shadcn/ui

## Status

Accepted

## Context

The template needs a flexible and maintainable UI foundation.

## Decision

Use Tailwind CSS, shadcn/ui, semantic CSS variables, and `src/components/ui` for design-system primitives.

## Consequences

### Benefits

- reusable UI primitives
- strong customization
- source-owned components
- consistent styling foundation

### Trade-offs

- generated UI components become part of the project source and must be maintained
