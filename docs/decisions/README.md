# Architectural Decision Records

This folder stores important architectural decisions for this template.

Create an ADR when a decision significantly affects architecture, dependencies, or project structure.

Do not create ADRs for small implementation details.

## Naming

```text
0001-example-decision.md
0002-another-decision.md
```

## Status

Common statuses:

- Proposed
- Accepted
- Superseded
- Deprecated
